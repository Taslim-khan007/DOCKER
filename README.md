# 🚀 Node.js + MongoDB Docker Application

A web application built with **Node.js, Express.js, MongoDB, and Docker** to register users and store their information in a database.

## ✨ Features

- 👤 User registration through an HTML form
- 💾 Store user data in MongoDB
- 📋 Fetch registered users using REST endpoints
- 🐳 Run MongoDB and Mongo Express using Docker Compose

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Frontend:** HTML, CSS
- **DevOps:** Docker, Docker Compose

## ⚙️ Installation & Setup

```bash
npm install
docker compose up -d
npm start
```

Open the application: http://localhost:3030

## 🌐 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Home page |
| GET | `/getUsers` | Fetch all users |
| POST | `/addUser` | Register a new user |
